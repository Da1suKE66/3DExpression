# IPP31078 v5 三条件操作说明

后续报告引用[统一实验基准](实验设置与报告引用基准_v5.md)，修改程序前阅读[开发交接](../DEVELOPMENT.md)。

先保存正在进行的旧会话，再自行关闭旧服务窗口并重启原Windows启动脚本；确认0.5.0 / ABC60-v5。不要在采集中更新页面。论文正文不在本轮修改。

1. **准备A素材**：由非参与者在“实时预览/录像”选择统一角色、同意、连接相机并中性校准。素材匿名编号STIMULUS01等，录制参数75–120秒，至少60秒有效连续序列。自然混合张嘴、眨眼、微笑、抬眉和放松，使用不等间隔，不看正式任务提示。停止并保存参数JSON及备份。不是手工关键帧；系统不附送虚构真人素材。
2. **人工检查并冻结**：用演示回放核对自然性，独立内部试采比较A/B幅度、类型与频率，正式采集前固定素材SHA。切换角色必须重新录制匹配素材/重新校准。旧v3.1/v4真实参数若驱动配置和角色一致可只读载入；没有抬眉变化等不满足新检查时需新录制。
3. **设置会话**：A/B/C页载入素材，确认非当前参与者、非任务编排。填匿名编号、internal/exploratory及真实顺序；P01–P06分别建议ABC、ACB、BAC、BCA、CAB、CBA，也可手动分配或随机选择。6人每序1人需操作者核对，不自动假定已配平。C附加延迟正式用400ms。
4. **真实校准后体验**：每条件60秒，适应10、基础20、自由20、整体10；三条件提示相同，每次结束立即答相同六题。休息至少15秒，不换角色、参数、窗口或校准。C预热不足时暂为中性，头部不延迟，任务时长仍60秒。失跟/暂停/隐藏页会清空队列；时间戳异常需核对后手动继续。
5. **偏好和保存**：三次问卷后选模式A/B/C或无明显偏好。完成后“保存到项目”，另下载完整JSON、参数CSV、自评CSV、偏好CSV。JSON包含三条件和偏好；六题新表为participants_v5.csv，偏好在三行评分中作为同一会话元数据重复保存，分析时不能算3次偏好。旧表不动，重复同内容保存不增行，冲突不覆盖。

真人验收应实际完成六种顺序，检查每条件恰好60秒后进问卷、三题组对应位置正确、偏好有时间戳和匿名会话关联。C核对feedback_input_timestamp_ms对应本条件早先输入，actual_buffer_delay_ms接近400且不早于设定；切换/失跟后先预热，不能残留上一条件动作。记录实际设备和异常。软件内部等待不是屏幕端到端视觉延迟，后者另拍外部同框视频。

python launch.py analyze或原分析脚本只汇总v5默认400ms，输出data/processed/abc_v5；非默认延迟与历史A/B不混算。工程性能、明确中性保持、逐动作肉眼成功数和恢复仍可用原工程评估入口；没有观察的指标保持未核对。

尚未由自动化代替的人工工作：录制真实素材及自然性检查、相机/头部/面部真实运行、实际延迟分布与渲染、A/B/C活动量匹配、问卷采集及外部视觉时延。测试夹具不是真人记录。
